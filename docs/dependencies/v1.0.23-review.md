## Update sweep

`cargo update --dry-run` offered three compatible changes:

- Applied only crc32fast 1.5.4 -> 1.5.5. Windows dependency path is
  wax-app -> eframe -> image -> png/flate2 -> crc32fast. Upstream comparison:
  https://github.com/srijs/rust-crc32fast/compare/v1.5.4...v1.5.5
  Changes concern ARM CRC kernels and tests; no Windows x64 speedup is claimed.
- Held rustls-pki-types 1.15.1 -> 1.16.0 and webpki-root-certs 1.0.11 -> 1.0.12
  because TLS/certificate behavior needs separate review under this candidate's
  no-networking-change scope. No automatic broad update was applied.

The lockfile changes one third-party package plus the app's own release version.
No dependency was removed. No claim that the retained warnings are fixed.

## Limits

RustSec matches known advisories against crate versions. It does not inspect
waX source behavior, vendored renderer modifications, WireGuardNT binary,
installer code, OS components, credentials, exploit reachability, runtime
configuration or unknown issues. No penetration test, source-code audit or
independent binary-signature review was performed. PE import checks and hosted
Windows functional checks remain separate evidence, not vulnerability scans.
